# Venture 3D Studio
A client-side Three.js design studio for the CLAV compression jersey. Its 19 editable garment components were modeled from the Mission 1 sketch. The rear shape and dimensions are design estimates. Seven additional multipart templates are included.

Run `python3 build.py` and `python3 -m http.server 8000 --directory dist`, then open http://localhost:8000. All runtime assets are bundled. Use GitHub Actions as the repository’s Pages source to deploy the same build under /Venture-3D-Studio/.
